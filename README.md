# TG WS Proxy для Android

Неофициальная Android-версия [Flowseal/tg-ws-proxy](https://github.com/Flowseal/tg-ws-proxy): локальный MTProto-прокси с WebSocket-маршрутами Telegram и резервными маршрутами исходного ядра.

**Android 7.0+ · ARM64 / x86_64 · ядро 1.11.4 · MIT**

## Скачать и подключить

APK размещён в [релизах](https://github.com/everth1337/tg-ws-proxy-android/releases). Первая версия — тестовая сборка, подписанная локальным отладочным ключом.

1. Установите APK и откройте TG WS Proxy.
2. Нажмите **«Запустить прокси»** и разрешите уведомления.
3. Нажмите **«Подключить Telegram»**, затем подтвердите прокси в Telegram или совместимом клиенте.
4. На Xiaomi и других телефонах с ограничениями фона разрешите приложению работать без ограничений батареи, если служба завершается.

Прокси слушает `127.0.0.1:1443` на самом телефоне. Секрет создаётся автоматически и сохраняется между запусками. Порт и собственный CF-домен доступны в настройках. После остановки службы отключите этот прокси в Telegram.

## Возможности

- Нативный интерфейс с запуском, остановкой, статистикой трафика и журналом.
- Фоновая служба с уведомлением и кнопкой остановки.
- Восстановление соединений при переходе Wi-Fi ↔ мобильная сеть, изменении DNS или IP-адреса; кнопка «Переподключить».
- Подключение клиента через `tg://proxy` и копирование ссылки.
- Штатные маршруты DC2/DC4 и пул соединений размером 4.
- Личный Cloudflare Worker с отдельным ключом доступа — [готовый код и настройка](cloudflare/README.md).
- WS, CF fallback, HTTP/2 для медиа и TCP fallback исходного проекта.

Работа зависит от доступности маршрутов в вашей сети. В стандартном режиме подтверждены подключение AyuGram и передача данных через DC2/DC4; резервные DC1/DC3/DC5 под нагрузкой могут не ответить. В режиме личного Worker проверены все DC1–DC5 и официальный Telegram на реальной мобильной сети. Служба использует wake lock и расходует батарею; производитель телефона может ограничивать фон. После перезагрузки требуется ручной запуск.

Версия **1.11.4-android.2** исправляет сохранение старых соединений и задержек повторных попыток после смены сети. Переход Wi-Fi → эмулируемая мобильная сеть → Wi-Fi проверен на Android 15. Эта проверка не воспроизводит фильтрацию реального мобильного оператора. Если при запуске сразу на мобильных данных связи нет даже после «Переподключить», нужны проверка разрешения мобильного трафика для приложения и диагностика маршрутов в сети оператора.

В **1.11.4-android.3** добавлен режим личного Worker с ключом `AUTH_TOKEN`. На Samsung S23 FE с Android 16 прямые соединения с Telegram и 20 стандартных CF-маршрутов не проходили. После настройки отдельного [Cloudflare Worker](cloudflare/README.md) официальный Telegram подключился на мобильных данных без Wi-Fi и VPN. Проверены DC1–DC5, работа с выключенным экраном и возврат на Wi-Fi. Личный адрес и ключ владельца не включены в общий APK: для этого режима нужно развернуть собственный Worker и указать его адрес и ключ в настройках.

## Сборка

Нужны JDK 21, Python 3.13 и Android SDK Platform 36.1. Откройте `android/` в Android Studio или задайте путь к SDK через `ANDROID_HOME` / `android/local.properties`.

```sh
cd android
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
```

На Windows используйте `gradlew.bat`. APK появится в `android/app/build/outputs/apk/debug/app-debug.apk`.
