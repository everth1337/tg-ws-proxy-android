# Проверки TG WS Proxy Android

Дата: 16 ноября 2026 года. Неофициальный порт ядра Flowseal/tg-ws-proxy 1.11.4, исходный коммит `6690b788432fd0f59b0f38e228494bcd6bede1ca`.

## Сборка

- Java 21, Gradle 9.8.2, Android Gradle Plugin 9.4.1, Chaquopy 17.2.0, Python 3.13.
- `assembleDebug` и `assembleDebugAndroidTest`: успешно.
- `lintDebug`: успешно, 0 ошибок, 8 предупреждений (версии SDK/Gradle, локализация строк, резервное копирование старых Android, синхронное сохранение секрета, wake lock без таймаута).
- APK поддерживает Android 7.0+ и архитектуры arm64-v8a/x86_64. Подписан локальным отладочным ключом.
- Контрольная сумма APK записана в `SHA256.txt`.

## Эмулятор Android 15, x86_64

- Установка и открытие интерфейса: успешно; экран проверен визуально.
- Потоковое AES-CTR через Android JCA: вектор NIST SP 800-38A успешно, включая разбиение данных на части длиной 1/6/12/13 байт.
- Два цикла запуска/остановки foreground service: успешно. Порт доступен после запуска и закрыт после остановки.
- Повторная проверка lifecycle на финальном APK: успешно.
- Реальные запросы `req_pq_multi` через приложение к DC1–DC5: получен `resPQ`, случайный nonce совпадает для всех пяти DC.

Отдельный повтор этого теста: passed (0,74 с). Исходное ядро при переносе не изменялось.

## Физический телефон

Обнаружен телефон `2201116TG`, Android 13, ARM64; ADB подключён по Wi-Fi.

После включения пользователем разрешений MIUI APK установлен, приложение открывается. Инструментальные проверки AES-CTR и двух циклов запуска/остановки службы прошли на реальном устройстве, в том числе после окончательной настройки маршрутов.

Первый сетевой прогон на телефоне: DC1 — 22,51 с, DC2 — 13,70 с, DC3 — 19,39 с, DC4 — 0,44 с, DC5 — 5,71 с; для всех получены resPQ с правильным nonce. При выключенном экране повторный ответ DC4 получен за 0,27 с.

Проверка установленного AyuGram показала, что уменьшенный пул размером 1 и маршрут только DC4 приводят к перегрузке резервных маршрутов. В финальной версии восстановлены штатный размер пула 4 и прямые маршруты DC2/DC4. После этого DC2 ответил за 0,11 с, DC4 — за 0,14 с. AyuGram подключён через локальный прокси; статус «Подключение прокси…» исчез, счётчик прокси показал более 10 МБ полученных данных.

Повторный прогон с работающим AyuGram и выключенным экраном: DC2 — 0,34 с, DC4 — 0,56 с; резервные DC1/DC3/DC5 не ответили в течение 60 с. Поэтому доступность резервных маршрутов под нагрузкой не считается гарантированной. Для них может потребоваться собственный CF-домен. Эта зависимость от внешних маршрутов унаследована от исходного ядра.

Тестовый instrumentation-пакет после проверки удалён; основное приложение оставлено установленным. Временное увеличение таймаута экрана отменено, исходное значение 60 с восстановлено. Секреты, журналы телефона и его сетевой адрес в GitHub не загружаются.

## Пределы проверки

Успешный `resPQ` подтверждает передачу MTProto через Android-прокси и получение настоящего ответа Telegram. Проверено подключение существующего AyuGram, без отправки пользовательских сообщений. Звонки, ручная загрузка больших фото/видео и многочасовая работа не проверялись. Зависимость от внешних маршрутов и ограничения фоновой работы производителя сохраняются.
